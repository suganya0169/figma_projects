# Food Delivery App – UI/UX Design

## About the Project
A mobile food delivery app designed using Figma. This project focuses on creating a simple and user-friendly food ordering experience.

## Screens Included
- Splash Screen
- Login and Sign Up
- Home
- Search and Categories
- Food Details
- Cart and Checkout
- Order Success
- My Profile
- Notifications
- My Orders
- Address Management

## Tool Used
Figma

## Project Type
Mobile App UI/UX Design
